**The World on 19 November 2026** — one 1024×1024 front-page image summing up the world news of Thursday 19 November 2026: the Trump–Xi–Putin trilateral meeting at the APEC summit in Shenzhen; Anthropic's record-breaking $81bn IPO and Nasdaq debut; NASA's Voyager 1 becoming the first human-made object one light-day from Earth; the worldwide launch of Grand Theft Auto VI; the third attack in a week on the Crimean Bridge; and Hakeem Jeffries's nomination as US House Speaker, on track to be the first Black speaker. The image (`entry.png`) is drawn with a Python PIL script (`build_image.py`, flat-design panels with short labels); `main.ts` copies it to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
